# BidPilot — Payment Gateways + Referral System

## چرا ۴ درگاه؟ (همگی احراز سبک)

ایران: زرین‌پال عالی‌ست ولی احرازش متوسط است (کارت ملی + شبا + بررسی چندساعته).
کاربر می‌خواهد «آسان‌ترین» را انتخاب کند — به‌خصوص برای شروع سریع.

| درگاه | احراز | فعال‌سازی | نکته حرفه‌ای |
|-------|-------|-----------|--------------|
| **زیبال Zibal** 💚 | موبایل + شبا | **زیر ۲ ساعت — بدون لوگو/نماد** | بهترین برای تست سریع |
| **IDPay** 💙 | موبایل + شبا + کارت ملی | <۲۴ ساعت | API تمیز، لینک شخصی |
| **NextPay** 🧡 | موبایل + شبا | **آنی** | بدون نیاز به وب‌سایت |
| **ZarinPal** 💛 | کارت ملی + شبا + مدارک | چند ساعت | برندترین، سقف بالا |

همه ۴ درگاه یک interface دارند (`create/verify`). اگر کلید فروشنده تنظیم نشده باشد،
پرداخت **شبیه‌سازی** می‌شود تا کاربر UX را ببیند — سپس هر درگاهی را که دوست داشت فعال کند.

## تجربه کاربر برای پرداخت

1.  `/plans` → جزئیات پلن → دکمه **پرداخت**
2.  کارت انتخاب درگاه باز می‌شود: ۴ کارت با نشان «سبک / متوسط»، توضیح یک‌خطی، و لینک docs
3.  کاربر روی دلخواه می‌زند → همان منطق قبلی: لینک پرداخت + دکمه **بررسی پرداخت**
4.  تأیید هم از همان درگاه انجام می‌شود (نه فقط زرین‌پال)

## باشگاه دعوت (Referral) — ارتقای بدون خرید

**لینک شخصی** هر کاربر:

```
https://t.me/<bot_username>?start=ref_ABC123
```

دکمه **اشتراک‌گذاری** تلگرام + کپی لینک + QR ذهنی (متن لینک).

### سطوح پاداش (milestone)

| دعوت‌های موفق* | پاداش | نشان |
|---------------|-------|------|
| 3 | ۷ روز استارتر | 🥉 |
| 5 | ۱۵ روز استارتر | 🥈 |
| 10 | ۳۰ روز حرفه‌ای | 🥇 |
| 20 | ۳۰ روز سازمانی | 👑 |

*موفق = دوست با لینک وارد شده **و** اتصال بازار را تکمیل کرده (پلن فعال + حداقل ۱ سایت).
علاوه بر این، برای هر خرید پولی دوست → **+۷ روز از همان پلن** به دعوت‌کننده (بدون سقف).

### ضد تقلب
- خودارجاع مسدود
- هر `invitee_chat_id` فقط یک بار شمرده می‌شود
- duplicate/pending → qualified → purchased

### UI دعوت (/invite)

کارت دعوت یک نگاه، حرفه‌ای:

- هدر با تعداد کل + در انتظار
- نوار پیشرفت تا مایل‌استون بعدی (progress_bar)
- جدول ۵ دعوت اخیر با وضعیت
- دو CTA: **اشتراک لینک** (Telegram share URL) + **کپی**
- CTA ثانویه: دیدن leaderboard (اختیاری بعداً)

پیاده‌سازی: `src/bidpilot/subscriptions/referrals.py` + `bot_ui.referral_*`
