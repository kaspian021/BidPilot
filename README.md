# BidPilot 🚀

**ربات هوشمند پیشنهاددهی برای پارس‌کدرز (و هر مارکت‌پلیس دیگری) — بدون دخالت شما.**

پروژه‌های جدید سایت را زنده رصد می‌کند، متن پروژه را می‌خواند، قیمت را **داخل بازه‌ی اعلامی کارفرما** انتخاب می‌کند، یک پیشنهاد فارسی اختصاصی برای همان پروژه می‌نویسد، ارسال می‌کند و نتیجه را در **تلگرام** به شما اطلاع می‌دهد.

```
┌──────────────┐   ┌──────────┐   ┌────────┐   ┌────────────┐   ┌──────────┐   ┌──────────┐
│  Parscoders  │──▶│  Filter  │──▶│ Dedupe │──▶│  Pricing   │──▶│ Proposal │──▶│  Submit  │
│  (scrape)    │   │ (rules)  │   │ (SQL)  │   │ in range   │   │  (LLM)   │   │ +Notify  │
└──────────────┘   └──────────┘   └────────┘   └────────────┘   └──────────┘   └──────────┘
        ▲                                                                          │
        │                                                                          ▼
   scheduler (poll every N sec, jittered)                                   Telegram + DB
```

## چرا افزونه‌ی مرورگر نه؟

افزونه‌ی کروم فقط وقتی کار می‌کند که مرورگر باز و لاگین باشد. خواسته‌ی شما «حتی وقتی من در سایت نیستم» است، پس این یک **سرویس سمت‌سرور** است: روی یک VPS ارزان (یا Raspberry Pi/لپ‌تاپ همیشه‌روشن) اجرا می‌شود، ۲۴ ساعته رصد می‌کند و به تلگرام شما پیام می‌دهد.

## ✨ چه کارهایی می‌کند

| قابلیت | توضیح |
|---|---|
| 🔍 رصد زنده | چرخه‌ی زمان‌بندی‌شده با فاصله‌ی تصادفی (ضدبلاک) و چند صفحه |
| 🧠 فهم پروژه | متن کامل پروژه استخراج و برای تولید پیام تحلیل می‌شود |
| 💰 قیمت‌گذاری هوشمند | **همیشه داخل بازه‌ی کارفرما** — مثال: بازه‌ی ۵۰۰,۰۰۰ تا ۱,۵۰۰,۰۰۰ ← پیشنهاد **۱,۰۰۰,۰۰۰ تومان** |
| ✍️ متن اختصاصی | سلام و وقت بخیر → معرفی شما → چالش‌های همین پروژه و راه‌حل → قیمت و زمان تحویل → امضا |
| ✅ اعتبارسنجی متن | طول، زبان فارسی، نبود مارک‌داون، عبارت‌های ممنوعه، وجود قیمت — با یک پاس «تعمیر» خودکار |
| 🤖 ارسال خودکار | بدون نیاز به تأیید شما (قابل تنظیم روی حالت آزمایشی) |
| 📲 اطلاع تلگرام | پروژه‌ی جدید، متن پیشنهاد، قیمت، نتیجه ارسال، خطاها |
| 🗄️ حافظه‌ی دائمی | هر پروژه یک‌بار بررسی می‌شود؛ ری‌استارت هم dedupe را نمی‌شکند |
| 🛡️ ترمز ایمنی | سقف ساعتی/روزانه و فاصله‌ی حداقلی بین پیشنهادها |
| 🧩 معماری پلاگین | افزودن سایت جدید = یک کلاس + چند سلکتور در YAML (بدون دست‌زدن به هسته) |
| 🔐 بدون `.env` | همه‌ی اطلاعات را ویزارد (`bidpilot setup`) یا خود ربات تلگرام می‌پرسد و امن در `data/settings.json` نگه می‌دارد |
| 🆓 هوش مصنوعی رایگان و ماندگار | Groq / Gemini / OpenRouter / Mistral / Ollama — توکن رایگان، بدون انقضا، با fallback خودکار |
| 🎭 لحن و سبک دلخواه | از داخل تلگرام (`/style`) بگو چگونه و با چه لحنی پیشنهاد بنویسد؛ همان لحظه اعمال می‌شود |
| 🤖 مدیریت کامل از تلگرام | راه‌اندازی، تغییر پروفایل، تست کلید، وضعیت، پیش‌نمایش و حالت ارسال، همه در چت |
| 🧪 تست‌شده | ۱۲۵ تست واحد و یکپارچه، همه با HTTP شبیه‌سازی‌شده (بدون نیاز به حساب واقعی) |

## ⚡ شروع سریع (۳ دقیقه، بدون `.env`)

```bash
git clone https://github.com/<username>/bidpilot.git && cd bidpilot
python3 -m venv .venv && source .venv/bin/activate     # ویندوز: .venv\Scripts\activate
pip install -e ".[dev]"

bidpilot setup     # همه‌ی سؤال‌ها یک‌جا: توکن تلگرام، کلید هوش مصنوعی رایگان، حساب سایت، پروفایل، لحن
bidpilot bot       # کنترل کامل از تلگرام؛ ترمینال دوم: bidpilot run
```

**هیچ فایل `.env` لازم نیست.** `bidpilot setup` فقط از خودت می‌پرسد و هر پاسخ را
بلافاصله در `data/settings.json` ذخیره می‌کند (پوشه `0700`، فایل `0600`، در `.gitignore`).
بعداً هر چیزی را می‌توانی از داخل تلگرام عوض کنی؛ لازم نیست سرور را دست بزنی.

اولین بار که به ربات پیام می‌دهی، همان چت به‌عنوان «مالک» ثبت می‌شود و بقیه نمی‌توانند
دستور بدهند. هر وقت خواستی: `bidpilot setup --status` وضعیت را نشان می‌دهد.

### ۱) هوش مصنوعی رایگان و همیشگی

BidPilot با هر API سازگار با OpenAI کار می‌کند، اما پیش‌فرض‌ها روی سرویس‌هایی هستند که
**توکن رایگان با اعتبار ماندگار** می‌دهند (بدون کارت بانکی):

| سرویس | گرفتن کلید رایگان | مدل پیش‌فرض | نکته |
|---|---|---|---|
| **Groq** (پیش‌فرض) | [console.groq.com/keys](https://console.groq.com/keys) | `openai/gpt-oss-120b` | سریع‌ترین؛ سقف درخواست روزانه دارد |
| **Google Gemini** | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | `gemini-3.8-flash` | سهمیه‌ی رایگان روزانه |
| **OpenRouter** | [openrouter.ai/keys](https://openrouter.ai/keys) | `openrouter/free` | روتر خودکار مدل‌های `:free` |
| **Mistral** | [console.mistral.ai](https://console.mistral.ai/api-keys) | `mistral-small-latest` | حالت Free با محدودیت نرخ |
| **Ollama** (محلی) | — | `qwen2.5:14b` | بدون کلید، بدون اینترنت، بدون محدودیت |

> نام درست سرویس **Groq** است (با q)؛ محصول xAI که «Grok» نام دارد API رایگان دائمی ندارد.
> سقف رایگان یعنی ممکن است در ساعات شلوغ محدود شوی؛ برای همین `llm.fallbacks` می‌تواند
> کلید Gemini/OpenRouter را هم در اولویت دوم امتحان کند. اگر همه‌شان در دسترس نباشند،
> متن با قالب فارسی داخلی نوشته می‌شود و هیچ پیشنهادی از دست نمی‌رود.
> اگر سرویسی مدلی را بازنشسته کرد، فقط `llm.model` را عوض کن
> (`bidpilot settings set llm.model -v "…"`) — هیچ کدی نباید تغییر کند.

کلید در `bidpilot setup` یا با `/llm` در تلگرام گرفته و ذخیره می‌شود؛
`bidpilot doctor` و `/test` سالم بودنش را چک می‌کنند.

### ۲) اتصال تلگرام

1. در تلگرام به [`@BotFather`](https://t.me/BotFather) پیام بده → `/newbot` → توکن را بگیر.
2. توکن را در `bidpilot setup` بفرست (یا `/setup` داخل ربات).
3. به ربات خودت `/start` بده؛ `chat_id` خودکار ثبت می‌شود.

از آن به بعد همه‌چیز در چت است: `/status`، `/style`، `/profile`، `/llm`، `/market`،
`/preview`، `/mode`، `/test`. راهنمای کامل: `bidpilot bot` و `/help`.

### ۳) حساب سایت فریلنسری

در `bidpilot setup` (یا `/market` در تلگرام) یکی را انتخاب کن:

- **کوکی نشست** (ساده‌تر، پیشنهادی): در مرورگر لاگین کن → DevTools → Application → Cookies →
  مقدار `PHPSESSID` را کپی کن و بفرست.
- **نام کاربری و رمز**: ربات خودش لاگین می‌کند؛ اگر سایت کپچا داشت، کوکی بهتر است.

> کوکی مثل «رمز موقت» است؛ هرگز کامیت یا به کسی داده نمی‌شود. اگر منقضی شد،
> ربات در تلگرام خبر می‌دهد و با `/market` مقدار جدید را می‌فرستی.

### ۴) لحن و سبک پیشنهاد (دلخواه)

این بخش دقیقاً همان چیزی است که می‌خواهی: **به ربات بگو چگونه پیشنهاد بدهد.**

در تلگرام `/style` را بزن؛ یکی از لحن‌های آماده را انتخاب کن یا لحن دلخواهت را بنویس،
و در قدم بعد هر دستور سبکی داری بفرست:

```
/style
→ ۳) خودمانی و گرم
→ «همیشه اول یک سؤال درباره‌ی ددلاین بپرس، روی تحویل مرحله‌ای تأکید کن،
   از تعریف‌کردن از کارفرما پرهیز کن و جمله‌ها کوتاه باشند.»
```

همین کار از ترمینال:

```bash
bidpilot settings set proposal.tone -v "خودمانی و گرم"
bidpilot settings set proposal.style_instructions \
  -v "همیشه روی تحویل مرحله‌ای تأکید کن و از تعریف از کارفرما پرهیز کن."
```

این لحن و دستورها مستقیم داخل پرامپت مدل زبانی می‌روند (و بر لحن پیش‌فرض پروفایل اولویت دارند).
برای دیدن نتیجه: `/preview` در تلگرام یا `bidpilot preview --limit 2`.

### ۵) حالت ارسال

پیش‌فرض **آزمایشی** است: پیشنهاد ساخته می‌شود، در تلگرام می‌بینی، ولی چیزی روی سایت ثبت نمی‌شود.
وقتی راضی بودی:

```bash
bidpilot go-live       # چک‌لیست ایمنی + فعال‌سازی
bidpilot go-live --off # بازگشت فوری به آزمایشی
```

یا بدون ترمینال، در تلگرام: `/mode` → «واقعی».
راهنمای محافظه‌کارانه: [`docs/GO_LIVE_CHECKLIST.md`](docs/GO_LIVE_CHECKLIST.md)

```bash
bidpilot demo          # اجرای کامل روی داده‌ی آزمایشی، بدون شبکه و بدون حساب
bidpilot doctor        # بررسی سلامت تنظیمات و دسترسی‌ها
bidpilot once --dry-run
bidpilot run           # اجرای دائمی؛ یا: bidpilot bot --run (ربات + رصد با هم)
```

## 🧠 متن پیشنهاد چطور ساخته می‌شود؟

ساختار ثابت است (همان چیزی که خواسته‌اید) و محتوا از **متن همان پروژه** می‌آید:

```
سلام و وقت بخیر
من … هستم، برنامه‌نویس … با … سال تجربه در …   →  معرفی (فقط از پروفایل ذخیره‌شده)
درباره‌ی «عنوان پروژه» … ۳ تا ۵ چالش کلیدی + راه‌حل هر کدام   →  از تحلیل پروژه
جمع‌بندی: قیمت پیشنهادی … تومان، زمان تحویل … روز، آمادگی شروع
با احترام، …
```

- **با کلید LLM رایگان** (Groq / Gemini / OpenRouter / Mistral / Ollama): متن طبیعی، مخصوص همان پروژه و با **لحن و دستورهای سبک خودت**؛ اگر سرویس اصلی سقف بخورد، سرویس بعدی امتحان می‌شود.
- **بدون کلید LLM**: یک موتور قالب + «بانک دانش» فارسی (playbook) که بر اساس کلیدواژه‌های پروژه (ربات، درگاه، ووکامرس، API، سئو، …) چالش و راه‌حل متناسب می‌نویسد. خروجی همیشه معتبر و پروژه‌محور است (لحن آزاد فقط با LLM اعمال می‌شود).
- هر متن قبل از ارسال **اعتبارسنجی** می‌شود؛ اگر رد شد، یک بار بازنویسی درخواست می‌شود و در نهایت به قالب برمی‌گردد.

### تنظیم قیمت

```yaml
pricing:
  strategy: "midpoint_round"   # midpoint_round | aggressive_low | premium_high | fixed
  ratio: 0.5                   # 0.0 = کف بازه، 0.5 = وسط، 1.0 = سقف بازه
  min_step: 5000               # رند کردن به عدد انسانی
  delivery_days: 14
```

| بازه‌ی کارفرما | ratio=0.5 | ratio=0.15 | ratio=0.85 |
|---|---|---|---|
| ۵۰۰,۰۰۰ – ۱,۵۰۰,۰۰۰ | **۱,۰۰۰,۰۰۰** | ۶۵۰,۰۰۰ | ۱,۳۵۰,۰۰۰ |
| ۲ – ۴ میلیون | ۳,۰۰۰,۰۰۰ | ۲,۳۰۰,۰۰۰ | ۳,۷۰۰,۰۰۰ |
| توافقی | `default_amount` | | |

قیمت هرگز از بازه بیرون نمی‌زند؛ حتی در استراتژی «fixed» هم به بازه clamp می‌شود.
پارسر بودجه فارسی است: `۵۰۰,۰۰۰ تا ۱,۵۰۰,۰۰۰ تومان`، `۵۰۰ تا ۱۵۰۰ تومن`، `۳۰۰ تا ۷۰۰ هزار`، `۲ تا ۴ میلیون`، `۵,۰۰۰,۰۰۰ ریال`، `توافقی`.

```python
@register_source("mysite")
class MySiteSource(Source):

    async def submit_bid(self, project, proposal, amount, delivery_days):
        ...                              # -> SubmissionResult
```

```yaml
# config/config.yaml
sources:
  - type: "mysite"
    enabled: true
    settings: {}
```

## 🖥️ دستورهای CLI

| دستور | کار |
|---|---|
| `bidpilot setup` | ویزارد کامل (بدون `.env`): تلگرام، LLM رایگان، حساب سایت، پروفایل، لحن |
| `bidpilot setup --status` | وضعیت راه‌اندازی و مقادیر ذخیره‌شده |
| `bidpilot bot` | ربات کنترل تلگرام (راه‌اندازی/لحن/وضعیت/پیش‌نمایش) |
| `bidpilot bot --run` | همان ربات + رصد و ارسال خودکار |
| `bidpilot settings show/set/unset/path` | مدیریت تنظیمات ذخیره‌شده از ترمینال |
| `bidpilot demo` | اجرای کامل روی داده‌ی آزمایشی (بدون شبکه) |
| `bidpilot doctor` | بررسی سلامت: پروفایل، تلگرام، LLM، دسترسی منابع |
| `bidpilot once [--live] [--limit N]` | یک دور کامل |
| `bidpilot run` | اجرای دائمی (daemon) |
| `bidpilot preview -s parscoders --limit 2` | دیدن متن پیشنهادی بدون ارسال/ذخیره |
| `bidpilot stats` | آمار پروژه‌ها و پیشنهادها |
| `bidpilot telegram-whoami` / `telegram-test` | راه‌اندازی و تست تلگرام |
| `bidpilot go-live` / `--off` | چک‌لیست ایمنی + فعال/غیرفعال کردن ارسال واقعی |
| `bidpilot inspect -u <url>` | دیباگ سلکتورها وقتی ظاهر سایت عوض شده |
| `bidpilot sources` / `initdb` | منابع ثبت‌شده / ساخت جدول‌ها |

## 🚀 اجرای دائمی

```bash
# Docker (ساده‌ترین)
docker compose run --rm bidpilot setup   # یک بار: پاسخ‌ها در volume «./data» می‌مانند
docker compose up -d --build
docker compose logs -f

# یا systemd روی VPS
sudo cp deploy/bidpilot.service /etc/systemd/system/
sudo systemctl enable --now bidpilot
journalctl -u bidpilot -f
```

اگر می‌خواهی ربات کنترل هم بالا باشد، در `docker-compose.yml` مقدار
`command: ["bot", "--run"]` را اضافه کن (یا `bidpilot bot --run` را در systemd بگذار).

برای مقیاس بزرگ‌تر: `DATABASE_URL=postgresql+asyncpg://...` و چند نمونه‌ی worker (dedupe از طریق unique index دیتابیس تضمین می‌شود). جزئیات: [`docs/DEPLOY.md`](docs/DEPLOY.md).

## ⚠️ نکات مهم و مسئولیت‌پذیری

- **قوانین سایت**: ارسال خودکار پیشنهاد ممکن است خلاف قوانین پارس‌کدرز یا مخل تجربه‌ی کارفرما تلقی شود. قبل از `live` کردن، شرایط استفاده‌ی سایت را بخوانید و ریسک را خودتان بپذیرید. توصیه: فاصله‌ی منطقی، سقف روزانه‌ی کم، و بازبینی دوره‌ای متن‌ها.
- **کیفیت پیشنهاد**: پیشنهاد خودکار باید صادق باشد. پروفایل و نمونه‌کارها را در `bidpilot setup` (یا `/profile`) واقعی وارد کنید؛ ادعای نمونه‌کار جعلی هم به شما آسیب می‌زند هم به کارفرما.
- **کوکی/توکن** = اعتبارنامه. تنظیمات در `data/settings.json` (chmod 600) ذخیره می‌شوند و پوشه‌ی `data/` در `.gitignore` است؛ اگر از `.env` استفاده می‌کنی (اختیاری) آن را هم هرگز کامیت نکن.
- **تغییر ظاهر سایت** ممکن است پارسر را بشکند؛ `bidpilot doctor` و لاگ‌ها سریع خبر می‌دهند و اصلاح با ویرایش YAML ممکن است.
- این پروژه **ابزار** است، نه مجوز نقض قوانین سایت‌ها.

## 📤 انتشار روی گیت‌هاب

این پروژه در همین workspace آماده است؛ برای ساختن ریپازیتوری روی حساب خودتان:

```bash
# روش ۱ — توکن (بدون نصب هیچ ابزاری)
export GH_TOKEN=ghp_xxxxxxxxxxxxxxxxx      # توکن با دسترسی repo
./scripts/publish_to_github.sh bidpilot private

# روش ۲ — GitHub CLI
gh auth login
./scripts/publish_to_github.sh bidpilot private
```

اسکریپت خودش `git init`، کامیت، ساخت ریپازیتوری و push را انجام می‌دهد و در پایان لینک را چاپ می‌کند.
(فایل `.env` و پوشه‌ی `data/` هرگز push نمی‌شوند.)

> اگر ارتباط GitHub را در تنظیمات Arena وصل کنید، خودم ریپازیتوری را می‌سازم و push می‌کنم.
