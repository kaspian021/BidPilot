# چک‌لیست رفتن به حالت live

هدف: اولین پیشنهاد واقعی را با کمترین ریسک بفرستید.

## ۰) پیش‌نیازها

| مورد | از کجا |
|---|---|
| توکن ربات تلگرام | `@BotFather` → `/newbot` → `TELEGRAM_BOT_TOKEN` |
| `chat_id` | به ربات پیام بدهید → `bidpilot telegram-whoami` → `TELEGRAM_CHAT_IDS` |
| کوکی پارس‌کدرز | لاگین در مرورگر → DevTools → Cookies → `PHPSESSID` → `PARSOCODERS_COOKIE` |
| پروفایل واقعی | `config/profile.yaml` (نام، تخصص، نمونه‌کارها، امضا) |
| کلید LLM (اختیاری) | `LLM_API_KEY` — بدون آن هم قالب فارسی کار می‌کند |

## ۱) اجرای آزمایشی

```bash
bidpilot doctor                  # همه‌ی ردیف‌ها OK؟ (منبع parscoders باید پروژه پیدا کند)
bidpilot telegram-test           # پیام تست رسید؟
bidpilot preview -s parscoders --limit 2    # متن‌ها را بخوانید؛ لحن و قیمت درست است؟
bidpilot once --dry-run --limit 3           # چرخه‌ی کامل بدون ارسال
```

## ۲) فعال‌سازی

```bash
bidpilot go-live      # چک‌لیست را اجرا و config/config.local.yaml را می‌سازد
bidpilot once --limit 1        # فقط یک پیشنهاد واقعی
```

بعد از دیدن نتیجه در تلگرام و روی سایت:

```bash
bidpilot run          # اجرای دائمی
```

بازگشت فوری به حالت آزمایشی: `bidpilot go-live --off`

## ۳) تنظیمات محافظه‌کارانه‌ی پیشنهادی برای شروع

```yaml
runtime:
  max_bids_per_hour: 3
  max_bids_per_day: 15
  min_seconds_between_bids: 300     # ۵ دقیقه بین پیشنهادها
  poll_interval_seconds: 180
filters:
  min_budget: 400000                # زیر ۴۰۰ هزار تومان پیشنهاد نده
  include_keywords: ["ربات", "پایتون", "api", "بک‌اند", "فروشگاه"]
```

هفته‌ی اول: روزی ۵ تا ۱۵ پیشنهاد با کیفیت، بهتر از ۵۰ پیشنهاد تکراری است.

## ۴) نشانه‌های هشدار

- پیام «نشست پارس‌کدرز منقضی شده» ← کوکی را به‌روز کنید.
- پیام «فرم ارسال پیشنهاد پیدا نشد» ← ظاهر سایت عوض شده: `bidpilot inspect -u <آدرس پروژه>` و اصلاح YAML.
- پیام «سقف ساعتی/روزانه پر شده» ← طبیعی است، یعنی ترمز کار می‌کند.
- «متن تولیدشده اعتبارسنجی را رد کرد» ← `proposal.on_generation_failure: "template"` را بگذارید یا مدل را عوض کنید.

## ۵) بازبینی هفتگی

```bash
bidpilot stats     # چند پروژه دید، چند پیشنهاد رفت، چند تا رد شد
```

اگر نرخ پاسخ کارفرما پایین بود: `pricing.ratio` را کمی پایین بیاورید (مثلاً ۰.۴) یا متن‌ها را با `preview` بازبینی کنید.

## ۶) اخلاق و قوانین

- پیشنهاد تکراری/کپی برای همه‌ی پروژه‌ها = سوختن اعتبار شما. سقف‌ها را کم نگه دارید.
- ادعای نمونه‌کار جعلی نکنید (پروفایل truthful باشد).
- شرایط استفاده‌ی سایت را بخوانید؛ مسئولیت ارسال خودکار با خودتان است.
