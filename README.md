# BidPilot 🚀

**ربات هوشمند پیشنهاددهی برای پارس‌کدرز (و هر مارکت‌پلیس دیگری) — بدون دخالت شما.**

پروژه‌های جدید سایت را زنده رصد می‌کند، متن پروژه را می‌خواند، قیمت را **داخل بازه‌ی اعلامی کارفرما** انتخاب می‌کند، یک پیشنهاد فارسی اختصاصی برای همان پروژه می‌نویسد، ارسال می‌کند و نتیجه را در **تلگرام** به شما اطلاع می‌دهد.

```
┌──────────────┐   ┌──────────┐   ┌────────┐   ┌────────────┐   ┌──────────┐   ┌──────────┐
│  Parscoders  │──▶│  Filter  │──▶│ Dedupe │──▶│  Pricing   │──▶│ Proposal │──▶│  Submit  │
│  (scrape)    │   │ (rules)  │   │ (SQL)  │   │ in range   │   │  (LLM)   │   │ +Notify  │
└──────────────┘   └──────────┘   └────────┘   └────────────┘   └──────────┘   └──────────┘
        ▲                                                                          │
        │                                                                          ▼
   scheduler (poll every N sec, jittered)                                   Telegram + DB
```

---

## چرا افزونه‌ی مرورگر نه؟

افزونه‌ی کروم فقط وقتی کار می‌کند که مرورگر باز و لاگین باشد. خواسته‌ی شما «حتی وقتی من در سایت نیستم» است، پس این یک **سرویس سمت‌سرور** است: روی یک VPS ارزان (یا Raspberry Pi/لپ‌تاپ همیشه‌روشن) اجرا می‌شود، ۲۴ ساعته رصد می‌کند و به تلگرام شما پیام می‌دهد.

## ✨ چه کارهایی می‌کند

| قابلیت | توضیح |
|---|---|
| 🔍 رصد زنده | چرخه‌ی زمان‌بندی‌شده با فاصله‌ی تصادفی (ضدبلاک) و چند صفحه |
| 🧠 فهم پروژه | متن کامل پروژه استخراج و برای تولید پیام تحلیل می‌شود |
| 💰 قیمت‌گذاری هوشمند | **همیشه داخل بازه‌ی کارفرما** — مثال: بازه‌ی ۵۰۰,۰۰۰ تا ۱,۵۰۰,۰۰۰ ← پیشنهاد **۱,۰۰۰,۰۰۰ تومان** |
| ✍️ متن اختصاصی | سلام و وقت بخیر → معرفی شما → چالش‌های همین پروژه و راه‌حل → قیمت و زمان تحویل → امضا |

| 🗄️ حافظه‌ی دائمی | هر پروژه یک‌بار بررسی می‌شود؛ ری‌استارت هم dedupe را نمی‌شکند |
| 🛡️ ترمز ایمنی | سقف ساعتی/روزانه و فاصله‌ی حداقلی بین پیشنهادها |
| 🧩 معماری پلاگین | افزودن سایت جدید = یک کلاس + چند سلکتور در YAML (بدون دست‌زدن به هسته) |
| 🧪 تست‌شده | ۷۰ تست واحد و یکپارچه، همه با HTTP شبیه‌سازی‌شده (بدون نیاز به حساب واقعی) |

## ⚡ شروع سریع (۵ دقیقه)

```bash
git clone https://github.com/<username>/bidpilot.git && cd bidpilot

python3 -m venv .venv && source .venv/bin/activate     # ویندوز: .venv\Scripts\activate
pip install -e ".[dev]"

cp .env.example .env        # توکن تلگرام و کوکی پارس‌کدرز را اینجا بگذارید
$EDITOR config/profile.yaml # نام، تخصص، نمونه‌کارها و امضای خودتان

bidpilot demo               # اجرای کامل روی داده‌ی آزمایشی، بدون شبکه و بدون حساب
bidpilot doctor             # بررسی سلامت تنظیمات و دسترسی‌ها
bidpilot preview -s parscoders --limit 2   # دیدن متن پیشنهادها بدون ارسال
bidpilot once --dry-run     # یک دور کامل، بدون ارسال واقعی
bidpilot run                # اجرای دائمی
```

### ۱) ربات تلگرام

1. در تلگرام به [`@BotFather`](https://t.me/BotFather) پیام بدهید → `/newbot` → توکن را در `.env` بگذارید.
2. به ربات خودتان یک پیام بدهید (`/start`).
3. `bidpilot telegram-whoami` → `chat_id` را در `.env` قرار دهید (`TELEGRAM_CHAT_IDS`).
4. `bidpilot telegram-test` برای تست اتصال.

### ۲) نشست پارس‌کدرز

در مرورگر لاگین کنید → DevTools → Application → Cookies → مقدار `PHPSESSID` را در `.env` بگذارید:

```env
PARSOCODERS_COOKIE="PHPSESSID=xxxxxxxxxxxxxxxx"
```

> این کوکی مثل «رمز ورود موقت» است؛ هرگز آن را کامیت یا به کسی ندهید. اگر منقضی شد، ربات در تلگرام خبر می‌دهد و باید مقدار جدید را بگذارید.

### ۳) حالت ارسال

```yaml
# config/config.yaml
runtime:
  submit_mode: "dry_run"   # "live" = ارسال واقعی پیشنهاد
```

تا وقتی با `live` راحت نیستید، همه‌چیز در حالت آزمایشی اجرا می‌شود: متن و قیمت ساخته می‌شود، در تلگرام می‌بینید، ولی چیزی ارسال نمی‌شود.

برای رفتن به حالت واقعی، از دستور چک‌لیست‌دار استفاده کنید (پروفایل، تلگرام، کوکی و سقف‌ها را بررسی می‌کند و تنظیم را در `config/config.local.yaml` می‌نویسد، نه در فایل اصلی):

```bash
bidpilot go-live       # فعال‌سازی ارسال واقعی
bidpilot go-live --off # بازگشت به حالت آزمایشی
```

راهنمای کامل و محافظه‌کارانه: [`docs/GO_LIVE_CHECKLIST.md`](docs/GO_LIVE_CHECKLIST.md)

## 🧠 متن پیشنهاد چطور ساخته می‌شود؟

ساختار ثابت است (همان چیزی که خواسته‌اید) و محتوا از **متن همان پروژه** می‌آید:

```
سلام و وقت بخیر
من … هستم، برنامه‌نویس … با … سال تجربه در …   →  معرفی (فقط از config/profile.yaml)
درباره‌ی «عنوان پروژه» … ۳ تا ۵ چالش کلیدی + راه‌حل هر کدام   →  از تحلیل پروژه
جمع‌بندی: قیمت پیشنهادی … تومان، زمان تحویل … روز، آمادگی شروع
با احترام، …
```

- **با کلید LLM** (OpenAI/OpenRouter/Groq/Ollama — هر چیزی که با API سازگار باشد): متن طبیعی و مخصوص همان پروژه.
- **بدون کلید LLM**: یک موتور قالب + «بانک دانش» فارسی (playbook) که بر اساس کلیدواژه‌های پروژه (ربات، درگاه، ووکامرس، API، سئو، …) چالش و راه‌حل متناسب می‌نویسد. خروجی همیشه معتبر و پروژه‌محور است.
- هر متن قبل از ارسال **اعتبارسنجی** می‌شود؛ اگر رد شد، یک بار بازنویسی درخواست می‌شود و در نهایت به قالب برمی‌گردد.

### تنظیم قیمت

```yaml
pricing:
  strategy: "midpoint_round"   # midpoint_round | aggressive_low | premium_high | fixed
  ratio: 0.5                   # 0.0 = کف بازه، 0.5 = وسط، 1.0 = سقف بازه
  min_step: 5000               # رند کردن به عدد انسانی
  delivery_days: 14
```

| بازه‌ی کارفرما | ratio=0.5 | ratio=0.15 | ratio=0.85 |
|---|---|---|---|
| ۵۰۰,۰۰۰ – ۱,۵۰۰,۰۰۰ | **۱,۰۰۰,۰۰۰** | ۶۵۰,۰۰۰ | ۱,۳۵۰,۰۰۰ |
| ۲ – ۴ میلیون | ۳,۰۰۰,۰۰۰ | ۲,۳۰۰,۰۰۰ | ۳,۷۰۰,۰۰۰ |
| توافقی | `default_amount` | | |

قیمت هرگز از بازه بیرون نمی‌زند؛ حتی در استراتژی «fixed» هم به بازه clamp می‌شود.
پارسر بودجه فارسی است: `۵۰۰,۰۰۰ تا ۱,۵۰۰,۰۰۰ تومان`، `۵۰۰ تا ۱۵۰۰ تومن`، `۳۰۰ تا ۷۰۰ هزار`، `۲ تا ۴ میلیون`، `۵,۰۰۰,۰۰۰ ریال`، `توافقی`.

## 🧩 افزودن یک سایت جدید

سه کار، بدون دست‌زدن به هسته:

```python
# src/bidpilot/sources/mysite/adapter.py
from ..base import Source
from ..registry import register_source

@register_source("mysite")
class MySiteSource(Source):
    async def fetch_projects(self):
        html = await self.get_html("/jobs")
        return parse_jobs(html)          # -> list[Project]

    async def submit_bid(self, project, proposal, amount, delivery_days):
        ...                              # -> SubmissionResult
```

```yaml
# config/config.yaml
sources:
  - type: "mysite"
    enabled: true
    settings: {}
```

و تمام: قیمت‌گذاری، تولید متن، ضدتکرار، تلگرام و دیتابیس همان‌طور کار می‌کنند. راهنمای کامل: [`docs/ADD_A_SOURCE.md`](docs/ADD_A_SOURCE.md).

## ⚠️ نکات مهم و مسئولیت‌پذیری

- **قوانین سایت**: ارسال خودکار پیشنهاد ممکن است خلاف قوانین پارس‌کدرز یا مخل تجربه‌ی کارفرما تلقی شود. قبل از `live` کردن، شرایط استفاده‌ی سایت را بخوانید و ریسک را خودتان بپذیرید. توصیه: فاصله‌ی منطقی، سقف روزانه‌ی کم، و بازبینی دوره‌ای متن‌ها.
- **کیفیت پیشنهاد**: پیشنهاد خودکار باید صادق باشد. `config/profile.yaml` را واقعی پر کنید؛ ادعای نمونه‌کار جعلی هم به شما آسیب می‌زند هم به کارفرما.
- **کوکی/توکن** = اعتبارنامه. `.env` را هرگز کامیت نکنید (پیش‌فرض در `.gitignore` است).
- **تغییر ظاهر سایت** ممکن است پارسر را بشکند؛ `bidpilot doctor` و لاگ‌ها سریع خبر می‌دهند و اصلاح با ویرایش YAML ممکن است.
- این پروژه **ابزار** است، نه مجوز نقض قوانین سایت‌ها.

```bash

./scripts/publish_to_github.sh bidpilot private
```

> اگر ارتباط GitHub را در تنظیمات Arena وصل کنید، خودم ریپازیتوری را می‌سازم و push می‌کنم.
